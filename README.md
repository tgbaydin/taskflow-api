# TaskFlow API

## Kurulum
```bash
npm install
node server.js
```

## Endpoint Listesi
- `GET /tasks` - Tum gorevleri listeler
- `POST /tasks` - Yeni gorev ekler
- `GET /tasks/:id` - Gorev detayi
- `PUT /tasks/:id` - Gorevi gunceller
- `DELETE /tasks/:id` - Gorevi siler
- `GET /reports/summary` - Genel sistem ozeti
