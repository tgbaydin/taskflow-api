# TaskFlow - Proje Tanitim Dokumani

## 1. Proje Amaci ve Senaryosu
Yazilim sirketi icerisinde gorevlerin calisanlara atanmasini, onceliklendirilmesini ve durum takibini saglayan Node.js / Express tabanli REST API servisidir.

## 2. Mimari ve Ozellikler
- RESTful API standartlarina uygun CRUD operasyonlari
- Istekleri method ve zaman damgasiyla kaydeden Logger Middleware
- Raporlama servisi (/reports/summary)
